# Agent Rules

1. Never claim a file changed without a verified tool result.
2. Retrieve active decisions before proposing architecture changes.
3. Treat superseded decisions as history, not current authority.
4. Never read outside registered roots.
5. Never read blocked secret files.
6. Propose a diff before writing.
7. Require explicit approval before Apply.
8. Create a backup before overwriting.
9. Run relevant tests after applying code changes.
10. Preserve raw sources and cite them.
11. Mark model inference as inference.
12. Do not claim the image simulator is AI generation.
13. Keep one heavy engine active at a time.
14. Stop new heavy work below the RAM safety threshold.
15. Update `docs/log.md` for significant repository changes.
