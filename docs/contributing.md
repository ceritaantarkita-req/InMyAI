# Contributing

1. Fork and create a focused branch.
2. Never commit personal project data or model weights.
3. Run `npm run setup`.
4. Use the Safe Mock provider in tests.
5. Add tests for behavioral changes.
6. Run `npm run qa`.
7. Update documentation and `docs/log.md`.
8. Explain RAM/VRAM impact for new engines or dependencies.
9. Keep optional heavy features behind extras/plugins.
