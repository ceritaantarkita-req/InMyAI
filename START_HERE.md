# Start Here

1. Read `README.md`.
2. Copy `.env.example` to `.env`.
3. Run `npm run setup`.
4. Run `npm run dev`.
5. Seed `examples/synthetic-project` using `scripts/seed_demo.py`.
6. Open `http://127.0.0.1:3000`.
7. Register only folders you intentionally allow.
8. Index the project.
9. Use Safe Mock first, then connect Ollama.
10. Run `npm run qa` before publishing changes.

The image-generation simulator is deliberately labeled as a simulator. Real local generation requires an optional local image runtime and model weights.
