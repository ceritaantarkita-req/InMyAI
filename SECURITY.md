# Security Policy

Please do not publish exploitable security issues in public issues.

For an actual public launch, configure a private security contact in this file or enable GitHub private vulnerability reporting. Include:

- affected version/commit
- operating system
- reproduction steps
- impact
- proof of concept without private user data

High-priority areas include filesystem path escape, secret-file exposure, unsafe command execution, model prompt injection leading to tool use, and artifact download traversal.
